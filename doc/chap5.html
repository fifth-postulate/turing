5 State

A turing state determines how a turing Machine acts upon reading a Symbol from the Tape.

There are two kinds of state: Regular states and Halting states. Halting states signal that the turing machine has halted.

gap> LoadPackage("turing");;
gap> q := TmState(1);
q1
gap> h := TmHalt(1);
h1
gap> IsTuringHaltState(q);
false
gap> IsTuringState(h);
true
gap> q = h;
false
