7 Machine

We finally have everything in play to start using a turing machine. We need a Tapeand a Program and we are set to run or step through the operations of the turing machine.

7.1 Example

In this example we will step throught a turing machine that keeps writing a series of I to the its tape.

gap> LoadPackage("turing");;
gap> tape := TmTape();
<tape empty>
gap> program := TmProgram(TmState(1));
<program empty>
gap> TmAddRule(program, TmState(1), TmBlank(), TmState(1), TmSymbol('I'), TmRight());
gap> machine := TmMachine(tape, program);
<machine q1 <tape empty>>
gap> TmStep(machine);
gap> machine;
<machine q1 <tape |_I[_]__|>>
gap> TmStep(machine);
gap> machine;
<machine q1 <tape |II[_]__|>>
